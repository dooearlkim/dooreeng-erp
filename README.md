# 두레이엔지 업무관리 (ERP)

동생분 혼자 쓰는 비공개 업무관리 프로그램입니다. 사무실 컴퓨터와 휴대폰에서 모두 쓸 수 있습니다.
데이터는 Supabase에 저장되고, 아이디 + 비밀번호 + 보안 질문(2단계)을 통과한 관리자만 볼 수 있습니다.
이 저장소에는 프로그램 코드만 있고, 매출·비용 같은 데이터는 들어 있지 않습니다.

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 홈 | 이번 달 매출·지출·이익, 받을 돈(미수금), 어음 만기, 줄 돈(미지급 인건비), 진행 중 현장 |
| 현장 | 현장 등록, 현장별 체크리스트(휴대폰으로 체크), 현장별 매출·인건비·비용·이익 |
| 매출·수금 | 매출(세금계산서) 등록, 수금 등록, 거래처별 미수금, 어음 만기 관리 |
| 비용·자재 | 자재 구매·식대·주유 등 비용 입력, 부가세 공제분 자동 계산 |
| 인력 | 출역(공수)·인건비 입력, 작업자별 미지급 정산, 인력 명단 |
| 거래처 | 원청사·시설관리업체·구매처 등록, 거래처별 매출·미수금 |
| 세금·회계 | 월별 손익, 부가세 예상(1기·2기), 현장별 이익, 엑셀(CSV) 내보내기 |

## 처음 설정 (한 번만)

1. Supabase SQL Editor 에서 `supabase/erp.sql` 내용을 붙여넣고 **Run**
   (홈페이지 때 만든 관리자 2단계 로그인을 그대로 사용합니다)
2. GitHub 저장소 **Settings → Pages** 에서 Branch 를 **main**, 폴더 **/ (root)** 로 하고 **Save**

## 고치는 방법

- 메뉴 항목, 비용 항목, 작업 종류 같은 목록: `app.js` 위쪽의 `EXP_CATS`, `WORK_TYPES` 등
- 화면 색·크기: `style.css`
- 파일을 고친 뒤 화면이 안 바뀌면 `index.html` 의 `?v=` 뒤 숫자를 올립니다
